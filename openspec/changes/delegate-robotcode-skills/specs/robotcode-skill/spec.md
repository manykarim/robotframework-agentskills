## REMOVED Requirements

### Requirement: robotcode skill exists and follows the house structure
**Reason**: `rf-robotcode` is retired. The RobotCode project's own plugin (`robotcode@robotframework-agent-plugins`) ships a `robotcode` skill for the same CLI and keeps it in step with each robotcode release.

**Migration**: Install the robotcode plugin from `robotcodedev/robotframework-agent-plugins` (the RobotCode VS Code extension already bundles it). Known limitations that still reproduce on robotcode 2.8 are reported upstream (see `robotcode-prerequisite`). Upgrades remove the `rf-robotcode` directory (see `skill-catalog`).
