## REMOVED Requirements

### Requirement: One libdoc skill replaces search and explain
**Reason**: `rf-libdoc` and its `rf_libdoc.py` script are retired. robotcode 2.8 answers the same questions in the project environment with `robotcode doc keywords <Target> [PATTERN]` and `robotcode doc keyword <Target> "<Keyword>"`, which honour `robot.toml`, profiles and import arguments. robotcode is now a documented prerequisite.

**Migration**: Use `robotcode doc keywords` / `robotcode doc keyword` (or REPL `.kw`). Skills and subagents name these commands inline. Upgrades remove the `rf-libdoc` directory and its Claude Desktop archive (see `skill-catalog`).
